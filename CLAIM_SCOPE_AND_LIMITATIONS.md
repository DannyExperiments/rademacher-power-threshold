# Claim scope

For independent symmetric signs and exact real weights j^α, with 0 < α ≤ 1/2, almost surely every nonempty open interval is visited infinitely often when α ≤ 1/4. When 1/4 < α ≤ 1/2, the absolute walk position tends to infinity almost surely.

The claim addresses exact real powers and visits to open intervals. It does not assert infinitely many exact returns to a point or extend to arbitrary sequences of comparable growth.

The release contains an analytic mathematical argument, a finite exact replay of selected algebraic steps, and an illustrative rotating figure. No proof-assistant formalization is included. The manuscript has not been peer reviewed.
