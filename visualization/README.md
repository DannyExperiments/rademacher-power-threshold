# Where the two scales cross

The axes show α from 0 to 1/2, log₂ N from 0 to 12, and the base-2 logarithm of each power-law scale. The two surfaces meet at α = 1/4. To the right, cluster size grows faster than expected visits. The theorem compares bounds with unspecified constants, so the diagram shows exponents only.

Extract `visit-and-cluster-scales-explorer.zip` and open `index.html` in a browser. The explorer runs offline. Adjust the angle with the Rotate slider or use the play button.
