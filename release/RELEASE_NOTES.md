# v1.0.0

For independent symmetric signs and exact real weights j^α, with 0 < α ≤ 1/2, almost surely every nonempty open interval is visited infinitely often when α ≤ 1/4. When 1/4 < α ≤ 1/2, the absolute walk position tends to infinity almost surely.

The exact replay checks 49 balanced-sign variance fixtures, 40 rational exponent fixtures, and the critical equality. The independent downloads comprise the paper, TeX source, bibliography, citation, repository checksums and versioned evidence archive. The version record is https://doi.org/10.5281/zenodo.24588799.
